# Glossário

| Termo | Significado |
|---|---|
| **Acesso aberto (OA)** | Artigo que a fonte informa como livre para leitura; só ele tem texto completo disponível para baixar |
| **Alerta** | Aviso no sininho de **artigo novo** sobre um interesse escolhido |
| **ANVISA** | Agência Nacional de Vigilância Sanitária; fonte do registro de medicamentos |
| **Aviso / notificação** | Item da caixa do sininho: artigo novo, retratação, mudança regulatória ou novidade de relatório |
| **Baseline (linha de base)** | Primeira verificação de um interesse: só registra o que já existe, sem avisar |
| **Biblioteca** | Artigos salvos pela conta, com etiquetas |
| **Catálogo** | Adaptador de uma fonte de busca (Europe PMC, PubMed…) que converte para o modelo `Work` |
| **Conitec** | Comissão Nacional de Incorporação de Tecnologias no SUS; emite recomendações sobre medicamentos |
| **Cobertura (da nota)** | Quanto do peso total dos critérios pôde ser avaliado; abaixo de 50% a nota é indeterminada |
| **CSP** | *Content Security Policy*; política que limita o que o navegador carrega e executa |
| **Critério (de confiabilidade)** | Um dos 8 sinais verificáveis que compõem a nota (integridade, desenho, revisão por pares, amostra, resultado, precisão, método, registro) |
| **Dedupe** | Remoção de resultados repetidos entre fontes, por DOI, PMID ou título |
| **Desenho do estudo** | Tipo de estudo (ensaio, coorte, revisão sistemática…), tirado do registro oficial |
| **Enriquecimento** | Dados extras do artigo vindos de fontes abertas (ensaios, citações, dados relacionados) |
| **Feed** | Novidades de fontes acadêmicas curadas (título, trecho curto e link) |
| **Ficha de leitura** | Documento com resumo, números, nota explicada, registro e citações |
| **Fonte (do feed)** | Site com feed RSS/Atom público; classificada por tipo |
| **IC (intervalo de confiança)** | Medida de precisão estatística; critério da nota |
| **Instantâneo (*snapshot*)** | Arquivo JSON versionado com os dados oficiais do Brasil |
| **Interesse** | Área, subtema, idioma ou palavra-chave que a pessoa acompanha |
| **JATS** | Formato XML de texto completo da Europe PMC |
| **Laboratório de IA** | Parte opcional (`/ia`) com análises geradas por modelo de linguagem |
| **LGPD** | Lei Geral de Proteção de Dados (Lei 13.709/2018) |
| **Lista de leitura** | Conjunto nomeado de artigos, compartilhável por link público somente leitura |
| **LLM** | Modelo de linguagem de grande porte (Groq, Ollama) |
| **Nota de confiabilidade** | Pontuação de 0 a 100 com 8 critérios abertos; não mede a qualidade real do estudo |
| **PICO** | Estrutura de pergunta clínica: População, Intervenção, Comparação, *Outcome* |
| **PMID / PMCID** | Identificadores do PubMed / do PubMed Central |
| **Panorama do tema** | Retrato visual dos primeiros resultados de uma busca |
| **Preprint** | Trabalho divulgado sem revisão por pares |
| **Rename** | Relação Nacional de Medicamentos Essenciais |
| **Relatório de tema** | Documento gerado a partir de uma lista, com panorama, nota por estudo, referências e apêndice de método |
| **Retratação** | Artigo retirado pelo editor ou autores; a nota vira 0 |
| **Sem IA** | Calculado ou copiado por código, sem geração de texto por modelo |
| **Sininho** | Ícone de avisos no topo (exige conta) |
| **SPA** | *Single-page application*; o navegador de artigos carrega uma vez e troca de tela por hash |
| **SSRF** | Falsificação de requisição do lado do servidor; evitada em `security.safe_get` |
| **SUS** | Sistema Único de Saúde |
| **Tier (tipo da fonte)** | Instituição, revista, preprint, divulgação científica, blog acadêmico ou jornal |
| **TTL** | Tempo de vida de uma entrada de cache |
| **Work (obra)** | Objeto do domínio que representa um artigo, em formato único para todas as fontes |
